# 시간표 네고시에이터

기능 1~5를 구현한 한국어 Streamlit 프로토타입입니다. 새 모임에는 영문 대문자와 숫자가 섞인 5자리 초대 코드가 발급되며 별도 입장 비밀번호는 사용하지 않습니다. 일정 겹침, 우선도, 필수 참석 조건을 모두 Python 규칙으로 처리합니다. 외부 API 호출·LLM·API 키가 필요하지 않습니다. Python 3.12에서 검증했습니다. 인터넷 주소로 공개하는 방법은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

## 실행

```powershell
cd schedule_negotiator
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

Windows에서는 `run.bat`을 더블클릭하면 됩니다. 브라우저에서 http://localhost:8501 을 엽니다. macOS/Linux는 `.venv/bin/python`을 사용하세요. 명령은 이 폴더에서 실행합니다.

## 체험 순서

1. 첫 화면에서 **모임장으로 참여하기**, **모임원으로 참여하기**, **기존 모임 참여하기** 중 하나를 선택합니다.
2. 모임장은 달력에서 후보 기간을 지정하고 모임 길이, 위치, 전체 인원을 설정합니다.
3. 모임장은 날짜·시간·마스킹·우선도를 선택해 자신의 스케줄을 입력하고 **나의 스케줄 제출**을 누릅니다.
4. 모임 생성이 완료되면 사이드바의 5자리 초대 코드 또는 참여 링크를 공유합니다.
5. 모임원은 초대 코드와 이름으로 최초 참여해 같은 방식으로 자신의 스케줄을 입력하고 제출합니다.
6. 설정한 인원이 전부 참여하고 제출하면 모임장이 **참여자** 메뉴에서 필수 참여자를 지정하고 추천 시간을 확인합니다.
7. 모임장과 모임원은 각자 발급된 5자리 개인 접속 코드 또는 개인 링크로 기존 모임에 다시 접속할 수 있습니다. 개인 코드를 입력하면 모임장·모임원 권한을 자동 판별합니다.

서로 다른 브라우저/시크릿 창에서 역할을 나눠 체험할 수 있습니다. 같은 서버와 데이터베이스에 접속해야 모임이 공유됩니다. 기본 서버는 로컬 PC에서만 접근 가능합니다. 인터넷 배포는 [DEPLOY.md](DEPLOY.md)를 따라 진행하세요. 샘플 버튼은 기본적으로 꺼져 있고, 환경변수 `SCHEDULE_ENABLE_DEMO=1`로 켤 수 있습니다.

후보 기간의 마지막 날이 지나면 앱이 다음에 실행되거나 새로고침될 때 해당 모임, 참여자, 일정 정보가 자동 삭제됩니다.

## 구현 범위

- 달력에서 직접 선택하는 시작일~종료일 후보 기간. 모임 길이 10~480분이며 시간과 10분 단위 분으로 설정.
- 모임 위치와 모임장을 포함한 전체 참여 인원 설정.
- 모든 참여자가 달력에서 날짜를 선택하고 시작·종료 시간, 일정 내용 마스킹, 우선도를 입력한 뒤 제출.
- 우선도 1: 변경 불가 / 2: 협의 필요 / 3: 조정 가능. 일정별 수정 가능.
- 모임장만 필수·비필수 지정 가능. 필수 인원의 우선도 1과 충돌하는 후보는 제외.
- 기본 비공개. 본인의 일정 또는 본인이 공개한 일정만 상세 내용 표시. 다른 사람의 비공개 내용은 SQL 조회 단계에서 `바쁨`으로 치환. 모임장도 예외 없음.

기능 6(이동 시간, 선호 시간, 모임 형태, 최소 인원), 외부 캘린더/메신저 연동, 자동 변경·확정은 포함하지 않습니다.

## 일정 입력

후보 기간 안에서 날짜를 달력으로 선택하고 시작·종료 시간을 10분 단위로 설정합니다. 일정 내용은 후보 계산에 사용되지 않으며, 마스킹을 켜면 다른 참여자에게는 `바쁨`으로만 표시됩니다. 우선도는 변경 불가·협의 필요·조정 가능 중 하나를 선택합니다. 참석이 어려운 시간이 없다면 일정 추가 없이 바로 스케줄을 제출할 수 있습니다.

## 후보 계산 규칙

- 설정한 전체 인원이 참여하고 전원 제출하기 전에는 추천하지 않습니다. 미참여자와 미제출자를 빈 시간으로 간주하지 않습니다.
- 각 날짜의 00:00~24:00를 10분 간격으로 탐색합니다. 모임 자체는 날짜 경계를 넘기지 않습니다.
- 구간은 시작 포함·종료 미포함입니다. 18:00에 끝나는 일정과 18:00에 시작하는 모임은 충돌하지 않습니다.
- 필수 인원의 우선도 1 충돌은 후보를 제외합니다. 비필수 인원의 우선도 1 충돌은 불참으로 표시합니다.
- 우선도 2·3 충돌은 당사자 동의가 필요한 **조건부** 참석입니다. 일정은 자동으로 바뀌지 않습니다.
- 불참 인원 수, 우선도 2 충돌 수, 우선도 3 충돌 수, 시작 시간 순으로 정렬합니다. 상위 12개를 표시합니다. 선호 시간 기능이 없으므로 입력 일정이 없으면 새벽 시간도 후보입니다.

## 저장과 프로토타입 한계

SQLite `data/schedule.db`에 저장됩니다. `SCHEDULE_DB` 환경변수로 별도 위치를 지정할 수 있습니다. 후보 기간 최대 32일, 모임 최대 30명, 한 번에 일정 30개까지 지원합니다. 제목·우선도·공개 여부 등은 서버에서 검증하고 DB 변경은 트랜잭션으로 처리합니다.

참가자 간 화면 프라이버시를 구현했습니다. 서버 관리자·파일 접근자로부터 DB 내용을 암호화하는 기능은 아닙니다. 초대 코드를 아는 사용자는 모임원으로 참여할 수 있으므로 코드는 참여자에게만 공유해야 합니다. 모임장 전용 수동 삭제와 후보 기간 종료 후 자동 삭제를 지원합니다. 공개 배포는 HTTPS 주소를 사용하세요. 저장 한계와 운영 설정은 [DEPLOY.md](DEPLOY.md)에 안내했습니다. 설치 후 앱의 일정 처리는 인터넷 연결과 API 키 없이 동작합니다.

## 테스트

```powershell
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest tests -q
```

핵심 로직, 참가자 간 권한·비공개 처리, 제출 상태, 자연어 해석, Streamlit 화면 흐름을 검증합니다. 네트워크 연결을 차단한 상태에서 해석·저장·추천까지 수행하는 테스트도 포함합니다.

## 구성

- `app.py`: Streamlit 화면과 사용자 흐름
- `core.py`: SQLite 저장소, 권한 확인, 규칙 기반 해석, 후보 계산
- `tests/`: 로직 및 화면 테스트
- `.streamlit/config.toml`: 로컬 서버와 테마

참고 문서: [Streamlit Forms](https://docs.streamlit.io/develop/concepts/architecture/forms), [Session State](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.session_state).
